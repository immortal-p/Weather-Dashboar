# Weather Dashboar

## Overview

The project is a weather information display panel with icons and additional parameters such as perceived temperature, humidity, wind speed, coordinates and time zone.


## Description

This project allows users to receive up-to-date weather information with a user-friendly and intuitive interface. The dashboard displays key weather data and environmental parameters.


## Installation

1.Clone the repository:
```bash
https://github.com/immortal-p/Weather-Dashboar.git
cd Weather-Dashboar
```

2.Install dependencies:
```bash
npm install
```

## Running the Project

```bash
make dev
```

(or `npm run dev`)


### Production build

```bash
make build
```

(or `npm run build`)
